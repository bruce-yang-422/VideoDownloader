說明
----
1. 開發執行輸出通常為 bin/Debug/net10.0/；建置／驗證產物可在相關程式停止且不需保留測試檔案時清理。
2. FFmpeg 也可使用程式 Tools 或 PATH 中的既有安裝。
3. 已移除舊的 Tools/SHA2-256SUMS；自動更新會從發行來源取得對應版本的校驗資料。
4. 設定與紀錄模型定義在 Services/UserDataService.cs；空的 Models 目錄與專案宣告已移除。
5. `*.m4s`、`*.part`、`.videodownloader-*` 是下載中或取消後可能產生的暫存檔，已由 `.gitignore` 排除。
6. 清理 obj 後，重新封裝前先執行 dotnet restore -r win-x64；IDE 可能自動重建 bin/obj。
7. build-installer.ps1 更新 installer-publish/ 與安裝包，不會同步更新 app-publish/；後者需另外 dotnet publish，指令見 README.md。
8. Tools/yt-dlp-plugins/ 的 .py 原始碼、Tests/ 測試原始碼、Assets/ 圖示及 installer/ 腳本應納入版本控制。
9. 主程式與 Threads 解析器透過新版發布檔更新；yt-dlp 自動更新，FFmpeg 僅在缺少或不可用時自動準備。
10. .gitignore 只控制 Git 忽略規則，不會刪除本機檔案；交付時保留完整 app-publish/ 或單一 Setup 安裝包。
11. About 作者為 Bruce Yang；版本、作者、Copyright、狀態與發布日期集中於 csproj，技術版本動態查詢。
12. About「檢查更新」沿用下載工具準備流程，不更新主程式；目前不提供 GitHub 專案連結按鈕。
13. 2026-09-10 重新封裝後已清理建置目錄、測試快取與封裝紀錄；保留檔案經 SHA256 核對未受影響，再更新本檔與 README.md。安裝包校驗值見 README.md。
