不納入版本控制但可重建的輸出
--------------------------------
以下目錄為 `.gitignore` 規則中的暫存/發布輸出，必要時可刪除後重建：

- bin/
- obj/
- artifacts/
- artifacts/installer-publish/
- .artifacts/
- .tmp 與所有 `*.log`、`*.tmp`、`*.temp`
- Tests/*/bin、Tests/*/obj
- Tools/yt-dlp.exe（若存在，通常作為離線初始檔）

建議清理命令：

```powershell
git clean -fdx
```

或等效地清除：

```powershell
Remove-Item -Recurse -Force bin, obj, artifacts
```

使用者資料與下載歷史（於執行機器本機）
----------------------------------
%LOCALAPPDATA%\VideoDownloader\
├── settings.json                  儲存格式、輸出資料夾、歷史等使用者偏好
└── history.json                   下載紀錄（成功、失敗、取消）

└── Tools\                        啟動時自動建立
    └── ffmpeg\                    下載並安裝的 ffmpeg/ffprobe（缺少時才建立）
